# PPGBG Restricted Access Dataset

This repository provides public documentation for the PPGBG dataset access process. The PPGBG dataset itself is restricted-access and is not distributed publicly through this repository.

## Access Policy

PPGBG is released under a restricted-access model. Access may be granted for legitimate research or educational use after review and approval of a data access request.

The data must not be used for clinical diagnosis, treatment decisions, direct patient care, participant re-identification, or redistribution. Applicants should read the data use agreement before submitting a request.

## How to Apply

1. Read the dataset documentation and data use agreement in this repository.
2. Prepare a data access request that includes:
   - applicant name, affiliation, role, and institutional email address;
   - project title and research purpose;
   - requested dataset scope;
   - data storage, access-control, and security plan;
   - ethics/IRB approval status, if applicable;
   - confirmation that the data will not be redistributed or used for re-identification.
3. Complete and sign the PPGBG data use agreement.
4. Send the request package to the dataset maintainers through the official contact channel listed in the dataset documentation, data use agreement, or associated publication.
5. Do not upload signed agreements, private applicant information, or other confidential materials to a public GitHub issue. If the correct private submission address is unclear, open a GitHub issue asking only for the private contact route.

## Repository Scope

This repository intentionally contains only public PPGBG access materials. It does not contain:

- PPG signal arrays;
- subject-, encounter-, or window-level data tables;
- full dataset release archives;
- BioMTL release data or documents.

## Citation

If access is approved and the dataset is used in a publication, please cite the associated PPGBG dataset paper and this repository. Bibliographic details should follow the final published version of the paper when available.
